09 / COURSE INTEGRATION

Five CAPP units, one system

Simulated sensors→Data processing→Decision logic→Signal control→Dashboard output
UNIT 01

Introduction to CAPP

Inputs are read, processed into decisions, and displayed as signal outputs, making the input-process-output flow visible.

UNIT 02

ALU

JavaScript functions add and subtract counts, compare road demand, calculate green duration, and evaluate logical alerts.

UNIT 03

Control unit

A single phase controller handles timers, manual/automatic operation, yellow clearance, all-red clearance, and safe phase selection.

UNIT 04

Parallel architecture

Independent asynchronous road-monitoring tasks are coordinated and compared with a sequential illustrative run. This is not proof of CPU parallelism.

UNIT 05

Parallel system

Traffic sensors, ALU, signal control, water monitoring, and emergency handling cooperate through shared simulation state.

PROJECT INFORMATION

Built for learning

Static HTML, CSS, and vanilla JavaScript. No backend, database, paid API, or build step. Settings and optional event history remain in this browser’s localStorage.

Not for real traffic control

Every count, signal, emergency, and water level is simulated for educational demonstration. Do not use this site to make real-world safety decisions.
